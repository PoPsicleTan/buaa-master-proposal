# 写作与排版

## 五章分别回答什么

| 章节 | 核心问题 | 应提供的材料 |
| --- | --- | --- |
| 选题依据 | 为什么研究这个问题？ | 场景、现有约束、意义与研究范围 |
| 国内外研究现状 | 已有方法做到哪里？ | 按问题组织的文献、同维度比较、研究空缺 |
| 研究目标与研究内容 | 准备做什么？ | 可检验的目标、相互衔接的研究内容、预期创新 |
| 研究方案与可行性分析 | 如何做、如何验证？ | 技术路线、实验设计、已有基础、风险预案 |
| 研究计划与预期成果 | 何时完成、交付什么？ | 时间表、阶段里程碑、成果及验收方式 |

如学院要求把进度安排并入研究方案，可将第五章中的两个 `\section` 移入第四章，
随后删除 `main.tex` 中对应的第五章 `\input`。不要重复写章节编号，编号由 LaTeX 自动生成。

## 引用与交叉引用

```latex
现有研究表明……\cite{your-reference-key}。
如图\ref{fig:route}所示，……
表\ref{tab:schedule}给出进度安排。
评价指标见式\eqref{eq:speedup}。
```

文献只需维护一份 `bibliography/references.bib`。默认只列出被引用的条目，按首次引用顺序编号，
使用 GB/T 7714—2015 顺序编码制。`\proposalbibliography{...}` 在新版宏包中选用
`gbt7714-2015-numeric`，旧版宏包中选用 `gbt7714-numerical`，避免因宏包默认版本变化而切换格式。
不要手写 `[1]`、图号或表号。
图表的 `\label` 放在 `\caption` 后，公式的 `\label` 放在公式环境内。

## 图表

图题放下方，表题放上方。正文先解释图表用途，再分析其中的内容。
较长的表格可用 `longtable`；短表优先用 `tabularx` 与 `booktabs`。
不要将 `table` 浮动体放入 `spacing` 环境，或通过大量负 `\vspace` 调整位置。
本模板将表内字号和行距限制在表格作用域内，避免影响后续正文。

## 提交前检查

替换所有填写提示、示例文献与占位图；核对每个数字和事实的出处；
区分已完成工作和拟开展工作；确认正文引用与文献条目相符；
最后检查封面、目录页码、空白页、长表跨页和图表清晰度，并按学院要求检查字体与章节。
